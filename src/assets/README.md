# Provider logo sources

- `openai.svg` is the black monoblossom mark from OpenAI's [2025 logo package](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip). Use follows [OpenAI's brand guidelines](https://openai.com/brand/).
- `deepseek.svg` uses the whale mark from DeepSeek's [official DeepSeek-LLM logo](https://github.com/deepseek-ai/DeepSeek-LLM/blob/main/images/logo.svg); its viewBox is cropped to the original symbol so the wordmark does not appear in the icon slot.
